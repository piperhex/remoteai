# ChatGPT 代理模式的上下文展示

代理运行时，ChatGPT 桌面端使用与 Codex GUI 一致的上下文圆环、百分比和 Token 数字格式。
点击圆环可以查看详情，齿轮打开当前对话的容量设置。尚未收到用量时也保留入口。

- 容量仅作用于当前本地对话，预设为 128、272、384、400、1000 K。
- 支持 1–100000 K，最多三位小数；1 K = 1000 Token。留空并保存恢复默认。
- 最近一次回复的实际容量与保存的设置分别展示，避免将预留空间误认为设置失效。
- 空闲对话保存后不发送消息。正在回复时，等待暂停完成，再应用容量并发送简短的继续消息。
- 修改期间手动停止会取消自动继续。保存或继续失败时，弹窗显示对应结果。
- 关闭代理或卸载注入后恢复原生展示，并清理观察器、定时器、弹窗及请求包装。

## 实现边界

`shared/context-usage` 与 GUI 共享计算、格式和容量校验规则。
`dream_skin_native/context_usage_*` 读取已提交的 React 属性并替换原生展示；
`context_settings_*` 通过原生本地对话管理器应用设置，不连接 GUI 的独立会话进程。

容量保存在 ChatGPT 当前配置目录的本地存储中，按对话 ID 隔离。
重新加载由原生对话管理器准备指令、工具和环境，再合并容量设置并保留当前模型及权限。
同一对话的修改与发送串行执行，其余对话不等待；恢复时不重放原来的用户输入。

原生组件和管理器通过能力特征识别，不依赖打包后的函数名。
不支持的组件保持原样；无法识别对话通道时，设置弹窗提示重试，不显示保存成功。
本功能仅接入本地代理对话，不覆盖云端或远程主机的容量设置。

用量和闪电按钮由单个节点持有；模型选择器换位置时移动该节点，并清理旧注入留下的重复节点。
