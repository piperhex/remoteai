# 手机和网页聊天设置

管理员可在 admin 的“聊天设置”页面统一设置手机 App 和网页聊天的以下选项：

| 选项 | 默认值 | 可设置范围 |
| --- | --- | --- |
| Relay 每秒传输量上限（每连接） | -1（不限） | -1 或正整数，单位 MiB/秒 |
| Relay 每秒帧数上限（每连接） | -1（不限） | -1 或正整数，单位帧/秒 |
| 每次加载的会话数 | 50 | 1–100 |
| 每次加载的历史消息数 | 10 | 1–100 |
| 添加图片的大小上限 | 20 MB | 1–20 MB |
| 压缩后图片最长边 | 2048 像素 | 256–4096 像素 |
| 每张图片压缩至 | 512 KB 以内 | 32–2048 KB |
| 单个文件上传上限 | 2 MB | 不小于 1 MB 的整数，不设上限 |
| 文件合计上传上限 | 3 MB | 不小于 1 MB 的整数，不设上限 |
| 文本文件查看上限 | 2 MB | 不小于 1 MB 的整数，不设上限 |
| 图片查看上限 | 20 MB | 1–20 MB |
| 文件下载上限 | 20 MB | 不小于 1 MB 的整数，不设上限 |

Relay 默认不限制每秒传输量和帧数。填写正整数后，连接超过所设阈值时会断开并重新连接。
旧配置缺少这两项时自动使用 -1。取消每片数据固定等待后，传输根据实际连接容量推进。

P2P 直连不受传输大小和图片压缩设置限制，可发送原图、大文件和较长的消息，并查看、下载较大的内容。
切换到 Relay 后，后续传输重新使用管理员设置；已经通过 P2P 传到电脑的待发消息可以继续发送。
会话和历史分页、每条消息的图片和文件数量限制仍然有效。

Relay 设置影响后续的图片和文件添加、查看和保存操作。已连接客户端通常在 5 秒内收到更新；
断线期间保留最近一次设置，重新连接时获取最新设置。已经显示或保存的内容不受影响。
图片以实际压缩结果的字节数检查目标大小，必要时继续降低画质和尺寸。
每条消息的图片和文件数量限制仍然有效。

“单个文件上传上限”对应手机聊天中从本机选择的文件，与文本预览、下载上限分别设置。
“文件合计上传上限”对应每次发送的文件总大小，多条待发消息一起发送时按合计大小检查。
两个上限分别设置，均按文件实际字节数判断；单文件同时受合计上限约束。
旧配置缺少这两项时分别使用 2 MB 和 3 MB，无需新增数据库字段。手机选取文件、电脑接收文件及发送待发消息时
都会检查最新限制；混合附件和消息传输的大小额度随合计上限扩大，大文件的等待时间也相应延长。
电脑端会再次检查 Relay 文件的大小，手机请求不能提高限制。P2P 接收的文件不受这些大小限制。
此项需要同步更新后台、admin UI、手机 App 和电脑端。

“文本文件查看”对应项目内的文本预览；“下载”对应现有的原图保存和文本导出，
网页图片查看器也提供下载按钮。这些设置不会新增其他文件格式的预览能力。
目前文本文件预览入口仅在手机 App 中提供，网页尚未提供该入口。
文件设置不再限制为 2 MB 和 20 MB；需同步更新后台、网页、手机 App 和电脑端，
旧版客户端仍可能拒绝超过原范围的设置。P2P 需同时更新电脑端和手机 App 或网页；
实际可处理的文件大小取决于设备可用资源。

## 安装与权限

先执行 `apps/admin/sql/20260913-chat-settings.sql`，再更新后台、admin UI、桌面端、网页和手机 App。
数据库没有保存记录时使用上述默认值。配置保存在 `chat_settings`，保存与审计记录在同一事务中提交。

- `admin.chat-settings.read`：查看配置。
- `admin.chat-settings.manage`：修改配置。

后台通过已认证的聊天连接下发设置，包括使用直连传输的设备；后台不读取聊天内容。
会话分页在两种连接方式下均使用管理员设置，文件查看大小限制仅用于 Relay。
图片缓存按查看上限区分，调整限制后的新请求会重新校验。
