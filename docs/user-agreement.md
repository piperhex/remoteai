# 登录用户协议

桌面端云账号登录及注册、移动端登录、网页端登录使用同一份协议。
中文正文位于 `shared/legal/zh.ts`，英文正文位于 `shared/legal/en.ts`；
版本号与提示文案位于 `shared/legal/agreement.ts`。

## 交互规则

- 每次打开登录表单时默认不勾选，不读取持久化的同意状态。
- 已勾选时直接提交；未勾选时先提示，选择“同意并登录”或“同意并注册”后再提交一次。
- 取消、关闭、阅读协议均不授予同意，也不发起登录请求。
- 在确认提示中阅读协议后，关闭正文会回到原来的确认提示。
- 按回车与点击登录遵循相同规则，重复点击不会并发提交。
- 网页端和移动端目前没有独立注册表单；网页注册引导仍指向桌面端。
- 本次记录限于当前表单中的用户选择，没有新增服务器端协议签署记录。

确认框最大宽度为 400px。正文阅读框最大宽度为 720px，并受视口高度限制；
正文单独滚动，关闭按钮保持可见。移动端使用安全区并支持系统返回操作。

## 内容维护

协议按当前产品能力起草，涵盖云端凭据同步、远程操作、模型及其他第三方服务、
运行信息、账号管理和用户权利。自建服务的实际运营者可能与开源项目维护者不同，
因此没有虚构运营公司、地址或联系方式，也没有承诺所有数据只保存在本机。

用户协议不代替实际运营者的隐私告知。公开运营前，实际运营者仍需确认其身份与联系渠道、
数据处理规则、保留期限、权利申请渠道及适用的收费规则，并审核协议是否符合实际服务。
涉及重要权益的实质性变更应同步更新两种语言和版本，并按需增加重新征求同意的流程。

起草时参考：

- [《中华人民共和国民法典》](https://www.cac.gov.cn/2020-06/01/c_15925617772683192.htm)：
  格式条款提示及公平确定双方权利义务的要求。
- [《中华人民共和国个人信息保护法》](https://www.stats.gov.cn/gk/tjfg/xgfxfg/202503/t20250310_1958923.html)：
  知情、自愿、明确同意及个人信息处理告知的要求。
