# 项目文件浏览器

文件内容工具栏提供“全屏浏览”：展开至当前窗口，收起外层标题和文件树，保留文件标签、编辑工具及保存入口。
图片、文档预览和空编辑区在文件标题栏提供同一入口。全屏时可以返回文件列表选择其他文件；再次点击按钮或按 Esc
恢复原布局，查找面板打开时 Esc 先关闭查找。Android 返回键先退出全屏，再返回聊天。切换保留草稿、光标和撤销记录。
桌面本地、桌面远程、宽屏及手机 Web、原生 WebView 共用全屏状态与布局；原生端保留系统安全区域。

桌面本地、桌面远程和宽屏 Web 的入口位于聊天输入框上方工具栏末尾，手机 Web 和原生应用的入口位于右上角工具菜单。

宽屏使用右侧抽屉：左侧按需展开文件树，右侧查看或编辑文件。抽屉左边缘和两栏分隔线均支持拖动、方向键调整，双击可恢复默认宽度。窄屏切换显示文件列表和内容，内容页可返回列表。

抽屉顶部的文件更改、预览、文件浏览、Git 和任务详情标签均可单独关闭。关闭当前标签后切换到相邻标签，关闭最后一个标签时收起抽屉；关闭其他标签不改变当前内容。关闭顶部标签会保留文件草稿及工具状态，从原入口重新打开即可继续。文件浏览内部的文件标签仍沿用原有未保存确认。

文件树顶部的搜索框支持按名称或相对路径查找项目内的文件和文件夹，不区分大小写，也能查找尚未展开的目录。结果显示相对路径，文件可直接打开或使用右键菜单，点击文件夹会回到文件树并展开到对应位置。清空搜索或按 Esc 恢复原文件树。搜索包括隐藏、依赖和生成目录，最多返回 50 项；达到扫描范围或时间限制时会提示缩小搜索范围。

文本编辑支持查找／替换、折叠、撤销／重做、行号、自动换行和保存。只有可识别语言的代码文件启用语法高亮，普通文本、日志和 Markdown 使用纯文本。超过 5 MB 的文本自动使用纯文本模式，保留查找、替换、撤销／重做和保存，关闭语法高亮、补全和折叠；编辑过程中超过阈值也会自动切换且保留草稿和撤销记录。支持 UTF-8 文本，保留原有 CRLF 换行；5 MB 以内的 PNG、JPEG、GIF、WebP 和 ICO 可预览。二进制、非 UTF-8 文件及超出预览范围的图片显示说明，不执行文件内容。目录按需展开，在后台读取全部可浏览项，不设条目数量上限；文件夹优先，再按名称排序。

文件区顶部支持多个标签，每个标签独立保留草稿，未保存时显示小圆点。点击文件名右侧的叉关闭标签；重新加载或关闭未保存的标签时可选择保存、放弃或取消。切换标签无需先保存，并保留撤销记录。

标签支持右键菜单，触屏可长按打开。可关闭当前、其他、全部、未修改或右侧的标签，也可复制路径和重命名。批量关闭会逐个确认尚未保存的文件，取消时保留这些标签。Ctrl+F4 关闭当前标签。

标签菜单支持向右、向下拆分，以及拆分并移动。每个编辑区域有独立的标签栏，文件树打开的文件进入当前区域；同一文件的多个视图共用草稿和保存状态。分隔线可拖动或用方向键调整，双击恢复均分。关闭文件的最后一个视图时才提示未保存修改，空区域会自动收起。窄屏将拆分区域上下排列，桌面、Web 和原生端关闭并重新打开文件浏览器后会保留布局。

文件树支持右键菜单，手机 Web 和原生应用通过长按打开，滑动时取消长按，普通点击仍用于浏览。菜单提供新建文件／文件夹、剪切、复制、复制路径、粘贴、重命名和删除；项目标题旁的菜单可在根目录中新建或粘贴。删除需要确认，同名目标不会被覆盖，复制到同一目录时自动添加副本名称。

文件与文件夹的二级菜单在鼠标悬停后从旁边展开，右侧空间不足时向左展开；方向键可进入和返回。窄屏保留点击进入及返回上一级的操作。

本地桌面提供系统文件浏览器和终端入口；远程提供下载，文件夹自动打包为 ZIP，保留空目录和原始文件内容。Web、桌面远程和 Android 复用下载列表；iOS 将文件保存到应用文档目录并打开预览。重命名和移动会同步更新已打开标签的路径并保留草稿，复制前需保存涉及的修改。

关闭抽屉只收起界面，当前连接中按项目保留标签、选中文件和修改，重新打开即可继续。桌面与 Web 保持编辑器挂载；原生端关闭前等待正在进行的保存完成，再由宿主保留草稿快照。这些草稿保存在内存中，不承诺刷新页面或重启应用后的恢复。

设置页和文件浏览器内的设置均可调整自动保存：默认停止输入 1 秒后保存，可选 2、5、10 秒或关闭。支持保存按钮、Ctrl+S 和 macOS 的 ⌘S。后台标签也会自动保存；保存期间新增的修改仍标为未保存，且同一文件不会并发写入。保存冲突后暂停自动重试，保留草稿供手动处理；断线时保留草稿并禁用保存。原生编辑器在应用进入后台时保持挂载，避免丢失草稿。

## SSH 文件浏览

PC 本地、PC 远程和 Web PC 的 SSH 文件页复用相同的文件树、多标签编辑器、分栏、搜索及自动保存设置。
文件树顶部保留主目录、上一级、隐藏文件开关、远程路径和上传入口；展开文件夹不会替换整个列表。
切换远程路径或跟随终端目录时，当前 SSH 会话的标签和草稿保持不变。窄窗口沿用本地浏览器的列表／内容切换。

SSH 沿用统一的 5 MB 纯文本切换阈值和图片预览范围，大文本通过分块读写继续编辑，保存保留 UTF-8 BOM 和换行格式。写入前重新读取并核对内容，
发现远程文件变化时保留草稿并提示重新加载；SFTP 上传不提供与其他远程进程之间的原子版本比较。
搜索按需读取子目录，最多返回 50 项、访问 128 个目录，并在 4 秒后停止发起新的目录请求；无法读取的子目录会使结果标为不完整。

新建、重命名、删除、剪切移动和复制路径使用共用菜单。SSH 接口暂不支持复制和文件夹 ZIP 下载，
对应操作保持不可用；单文件下载统一为 5 MB，编辑保存和上传支持更大的文件，并继续使用分块传输。
手机 Web 与原生端保留原有 SSH 文件界面。

## 实现与边界

- `shared/project-browser`：三端共用的文件树、CodeMirror 编辑器、草稿状态和手机消息桥。
- `projectFiles` 复用现有目录列表；`projectFileRead` 和 `projectFileWrite` 经本机或已认证远程聊天连接进入 Rust。
- `projectEntryAction` 使用限定的操作类型和项目路径，复用保存互斥锁，远程重试按请求 ID 去重。树操作拒绝项目外路径、链接和特殊文件；递归操作限制文件数量，ZIP 同时校验原始内容和归档大小。
- Rust 校验规范化后的文件路径必须位于所选项目内，拒绝网络地址和目录。阻塞读写及互斥锁均运行在线程池中。
- 文本读写使用 256 KB 分块，避免单条远程消息限制。读取后验证摘要；上传使用有时效和数量限制的临时文件，支持固定偏移重试与失败清理，完成后检查原文件版本并原子替换。5 MB 是编辑功能切换阈值，不是文本保存上限。
- 保存携带读取时的内容摘要，暂存后再次校验，使用临时文件替换目标。外部修改导致保存失败时，编辑草稿保持不变；不会自动覆盖冲突。
- 原生 WebView 只加载随应用打包的编辑器；禁止导航、网络和本机文件访问。项目根目录由原生宿主决定。

修改共享编辑器后，先运行 `npm run export:native` 更新 Native 的依赖快照，再运行 `node apps/native/scripts/build-project-browser.cjs` 更新原生资源。`npm --prefix apps/native run check` 会检查资源是否过期；首次开发需按 [Native 子模块说明](native-submodule.md) 初始化并安装依赖。

## 验证

- Rust：`cargo test --manifest-path apps/desktop/src-tauri/Cargo.toml --test codex_switch_lib_tests codex_gui::project_`。
- 桌面：`npx vitest run --config scripts/vitest.config.ts src/remoteChat/projectBrowser src/remoteChat/operations.test.ts`。
- 原生消息桥：`npm --prefix apps/native run test -- src/chat/projectBrowserBridge.test.ts`。
- 界面与原生资源：`npm run test:chat:e2e -w @codex-switch/desktop -- project-browser`。
- Android 独立测试包：在 `apps/native/android` 执行 `gradlew assembleRelease -I ../e2e/project-browser.init.gradle -PreactNativeArchitectures=arm64-v8a`，应用 ID 为 `com.codexswitch.mobile.filebrowsertest`。
- 设置 `ANDROID_SERIAL` 后运行 `node apps/native/e2e/project-browser-test.mjs`，测试会安装独立测试包并在结束后卸载，恢复此前打开的应用。
