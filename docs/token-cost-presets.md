# 模型计价预设

内置价格核对日期：2026-09-23。来源：[OpenAI API 定价](https://developers.openai.com/api/docs/pricing)。
价格单位为美元 / 每百万 Token，包含输入、缓存输入、输出和逐模型快速模式倍率。
GPT-5.6 Cyber 尚未公布快速模式价格，其倍率留空，按普通价格估算，管理员或用户可自行填写。

## 管理和同步

admin 的「模型计价」页面支持新增模型、修改价格、别名、来源链接和长上下文规则。
快速模式倍率位于每个模型的最后一列。留空表示未公布倍率；零不是有效倍率。
读取和编辑权限分别为 `admin.token-pricing.read`、`admin.token-pricing.manage`。
保存会记录审计日志；默认管理员角色启动时自动获得这两项权限。

PC 每次启动只请求一次 `/token-cost-presets`，无需登录；子窗口不会重复请求。
请求在后台执行，不阻塞界面。有效数据缓存在本地，离线或校验失败时继续使用上次缓存，
没有缓存时使用内置价格。新模型加入模型下拉列表，价格同步到原生统计和费用图表。

用户自定义价格优先于预设。快速模式按每模型自定义倍率、旧版本全局自定义倍率、
模型预设的顺序选取；清空某模型的自定义倍率后，该模型直接跟随预设。
未公布倍率时按 1 倍估算。普通请求不应用快速模式倍率。
长上下文默认超过 272,000 输入 Token 时，输入和缓存输入 2 倍、输出 1.5 倍；
只对启用长上下文计价的模型生效，无预设模型使用所选参考模型的规则。

## 服务与数据库

- 公开读取：`GET /token-cost-presets`，只返回价格数据并禁用 HTTP 缓存。
- 管理读取/保存：`GET/PATCH /admin/api/token-cost-presets`。
- 已有数据库先执行 `apps/admin/sql/20260923-token-cost-presets.sql`，新增独立配置表。
- 新空数据库初始化时会创建该表。没有保存记录时返回内置预设；重复迁移不会覆盖已保存价格。
- 后端只使用 admin-go，部署前按 [部署说明](../apps/admin/DEPLOYMENT.md)备份并验证迁移。

两份内置 JSON 分别供 PC 和 Go 编译使用，一致性由 `scripts/token-cost-presets.test.mjs` 检查。
官方价格变化时应同时更新这两份文件并复核模型来源链接。
